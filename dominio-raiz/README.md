# Domínio raiz do GitHub Pages (branding7dados-lab.github.io)

Cópia do que deve existir no repositório **branding7dados-lab.github.io**:

- `.well-known/assetlinks.json`: prova ao Android que o site é do app `br.com.branding7.sistemab7` (assinado com a chave do app). Com ele, o app abre em tela cheia, sem a barra do Chrome.
- `.nojekyll`: faz o GitHub Pages servir a pasta `.well-known` (o Jekyll esconde pastas que começam com ponto).

Se a chave do app mudar, o SHA-256 daqui tem que mudar junto.
