Falta ligar o banco

O sistema está no ar, mas ainda não sabe onde guardar os roteiros. Abra js/config.js e cole os dois valores do seu projeto no Supabase:

window.B7_CONFIG = {
  SUPABASE_URL: 'https://xxxxx.supabase.co',
  SUPABASE_PUBLISHABLE_KEY: 'sb_publishable_...'
};

Os dois estão em Supabase → Project Settings → API: Project URL e a chave anon / publishable. Nunca use a service_role aqui — este arquivo fica visível para quem abrir o site.

Antes disso, rode o supabase_setup.sql no SQL Editor. Passo a passo no README.md.
