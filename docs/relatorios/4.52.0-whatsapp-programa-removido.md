## 4.52.1 — "Puxar conversas recentes" não trazia mensagens
- Diagnóstico (wa-evolution GET ?diag=1, só contagens): número conectado (open), webhook
  ligado com os 8 eventos, Evolution com 25.387 mensagens guardadas — mas `findChats`
  responde 500 no MySQL ("Named and positional parameters mixed in one statement"), a
  consulta interna do Evolution é de Postgres. `findMessages` funciona.
- Correção: `importar` lê as mensagens mais recentes de todas as conversas direto pelo
  `findMessages` (150 por página, até 16 páginas ≈ 2.400), da mais antiga para a mais nova
  de cada página; as conversas saem das próprias mensagens. Grupos continuam vindo do
  `fetchAllGroups` (69 grupos, 21 já ligados a clientes pelo nome).
- Tela: a barra mostra mensagens trazidas.
