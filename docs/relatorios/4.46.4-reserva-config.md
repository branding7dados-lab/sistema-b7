# 4.46.4 — Fim da tela "Falta ligar o banco" por falha ao baixar o config.js

**Sintoma (Kevin, iPhone, 14/11):** o sistema abriu na tela de configuração "Falta ligar o banco".

**Causa:** essa tela aparece quando `js/config.js` não chega. O service worker busca esse arquivo sempre na rede
(2,5 s) e só cai para a cópia guardada se ela existir. Logo depois de uma atualização (ontem foram 4 versões), o
cache novo ainda não tem a cópia; com a internet lenta ou caindo, o arquivo não chegava e o sistema achava que o
banco não estava configurado.

**Correção:** `js/supabase.js` tem uma reserva embutida com os mesmos valores públicos (URL do projeto, chave
publishable, chave VAPID pública e as chaves da IA ligadas). Se `config.js` não carregar, usa a reserva; se carregar,
o arquivo continua valendo. Nenhuma chave secreta entrou no código.

**Teste:** Playwright com `config.js` bloqueado → abre o login normalmente (antes: tela de setup).
