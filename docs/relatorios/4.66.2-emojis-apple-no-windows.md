# 4.66.2 — Emojis da Apple também no Windows

## O problema
No computador com Windows, o sistema continuava mostrando os emojis do Windows.
No celular, no Mac e no Linux já apareciam os da Apple.

## A causa
O Windows só aceita uma fonte que tenha:
- a tabela de contornos (`glyf`/`loca`);
- os nomes no formato do Windows (`name`, plataforma 3).

A fonte de emojis da Apple para Linux (só desenhos coloridos CBDT) não tem nenhum dos dois.
Por isso o Windows recusava a fonte e usava os emojis dele.
É a mesma correção que o Google faz no "Noto Color Emoji – Windows compatible".

## O que mudou
- Os 19 pedaços em `assets/fonts/emoji/` ganharam:
  - contornos vazios (`glyf`/`loca`, com o `maxp` na versão 1.0);
  - os nomes no formato do Windows.
  - Os desenhos continuam os mesmos.
- `emoji.css` passou a chamar os arquivos com `?v=2`, para nenhum cache entregar o pedaço antigo.
- Conferido no Chromium: os emojis continuam aparecendo, inclusive tons de pele, bandeiras e famílias.
