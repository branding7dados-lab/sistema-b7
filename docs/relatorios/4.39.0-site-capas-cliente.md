# 4.39.0 — capas automáticas e cliente da lista (Site → Vídeos/Depoimentos)

- **Cliente selecionável**: no vídeo e no depoimento, o campo Cliente virou uma lista com os clientes do sistema; "Outro (digitar)…" abre o campo de texto para quem não está cadastrado. A aba Clientes (marcas avulsas) continua com texto livre.
- **Capa automática** (função `site-capa`, deploy sem verify_jwt; confere `sou_admin()` com o token de quem chama):
  - Instagram: `instagram.com/p/<código>/media/?size=l` redireciona para a capa (Reels vêm 1080×1920). YouTube: `img.youtube.com/vi/<id>/maxresdefault|hqdefault`.
  - A imagem é guardada em `site/capas/<ig|yt>-<código>.jpg` (o endereço do Instagram expira) e vira o `capa_url`.
  - Roda sozinha ao salvar um vídeo de link sem capa e ao abrir a aba Vídeos/Depoimentos quando algum está sem capa; botão **Atualizar capas** refaz todas.
  - Testado: o servidor do Supabase recebe a capa do Instagram (200, image/jpeg). Sem token de admin a função responde 403.
- Site (branding7-site): Trabalhos virou um trilho de Reels (capa, cliente, título, @, categoria com filtro, arrastar, setas), e as capas também aparecem na pilha da abertura e no celular 3D.
