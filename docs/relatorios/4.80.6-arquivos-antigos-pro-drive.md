# 4.80.6 — Arquivos do WhatsApp que ficaram no sistema vão para o Drive aos poucos

## O que o Kevin viu
A pasta "B7 · WhatsApp" não aparece no Drive, e o armazenamento `wa-midia` do Supabase tem uns 170–200 MB.

## Como funcionava
- O arquivo só é baixado do WhatsApp quando alguém abre (ou envia pelo B7).
- Na hora, se o Drive está conectado (`drive_conexoes.status = 'ativa'`), vai para o Drive. Se não, fica no
  armazenamento do sistema (`wa-midia`).
- O que caiu no sistema só ia para o Drive se alguém abrisse de novo com o Drive conectado. Nada levava os antigos.
- O escopo é `drive.file`: a pasta fica no Drive da conta Google que foi conectada (botão "Arquivos no Google Drive"
  da Central), não necessariamente na conta branding7dados.

## O que mudou
- `midiaParaDrive` saiu do `wa-evolution` e foi para `_shared/drive.ts`.
- Nova `levarAntigosProDrive(sb, 15)`: o relógio do Otto (a cada 5 min) leva até 15 arquivos do sistema para o Drive
  e apaga a cópia do sistema. Só roda com o Drive conectado. Arquivo que não existe mais no armazenamento perde a
  referência (ao abrir, o B7 busca de novo no WhatsApp).

## Não verificado
O acesso de leitura ao banco caiu nesta sessão: o conector do Supabase passou a mostrar só outro projeto, e o token
do GitHub responde "Missing required permission(s): database_read". Por isso não confirmei o status da conexão do
Drive nem o tamanho real do `wa-midia`. A consulta pronta está em `zzz377_diag_midia_wa.sql` (só leitura).
