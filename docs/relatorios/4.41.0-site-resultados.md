# 4.41.0 — resultados dos vídeos do site

- `site_itens`: `visualizacoes`, `curtidas`, `comentarios` (texto livre, ex. "126 mil") e `resultado` (até 140 caracteres, ex. "+30 matrículas no mês do vídeo") — zzz328.
- Site → Vídeos: bloco "Resultados" no formulário; a lista mostra visualizações e o resultado.
- Site (branding7-site): o cartão do vídeo mostra visualizações, curtidas e comentários com ícones e o resultado num selo em degradê.
- Os números não vêm sozinhos do Instagram (só pela API oficial da Meta, com a conta conectada); são digitados no painel.
- Muro da abertura: 3D (perspectiva, parado) quando o navegador desenha com placa de vídeo; 2D só girado (sem o skew que esticava) quando não há aceleração.
