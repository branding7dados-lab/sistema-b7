# 4.50.0 — WhatsApp do B7 pelo Evolution (piloto): conexão pelo QR Code (16/11/2026)

Kevin decidiu testar o Evolution API em vez de depender só do WhatsApp Web
embutido no programa, para no futuro ter a Central de Conversas no padrão B7
(navegador, Android e PC).

## Servidor (feito pelo Kevin, com o kit do repositório)
- Evolution API v2.3.7 rodando no Pterodactyl (egg `servidor/evolution/pterodactyl/
  egg-evolution-b7.json`), banco MySQL do painel (`s6_evolution`), porta 25570,
  público em `http://node.skyrixs.com:25570`. 18 tabelas criadas; "HTTP - ON".
- Secrets no Supabase: `EVOLUTION_URL`, `EVOLUTION_API_KEY` (não passaram pelo chat).

## B7
- Edge Function **wa-evolution** (supabase/functions/wa-evolution): única ponte com o
  Evolution; só administrador; ações `estado`, `conectar` (cria a conexão `b7-piloto` se
  não existir e devolve o QR Code), `desconectar`. GET = diagnóstico sem dado sensível.
  Publicada também pelo workflow `funcoes.yml`.
- Diagnóstico real depois dos secrets: `configurado: true`, Evolution respondeu 404 para a
  conexão ainda inexistente — ou seja, alcançável e com a chave aceita (chave errada daria 401).
- js/wa-central.js (novo): janela "WhatsApp do B7" — estado, QR Code com instruções,
  renova o QR a cada 45 s, detecta a leitura (consulta a cada 3 s) e mostra "Conectado"
  com o número; botão para desconectar. Botão "WhatsApp B7 (piloto)" na tela do WhatsApp
  (programa e navegador), só para administrador.
- js/database.js `waEvolution(acao)`; styles/sistema.css bloco `.wac`.

## Testes
- Função publicada: GET responde; POST sem sessão → 401.
- Tela com a função simulada (Playwright): sem conexão → QR → conectado, sem erros.
- Não testado: a leitura real do QR (precisa do celular do número do piloto).
