# 4.46.3 — Cargo da equipe no site a partir das funções do sistema

- zzz337: `site_itens.cargo_perfil`; `_site_cargo_de(perfil)` monta "função principal (ou personalizada) · funções
  adicionais" (ex.: Kevin → "Videomaker · Designer"). Gatilho antes de salvar o item recalcula o cargo; gatilho em
  `perfis` (funcao, funcoes_adicionais, funcao_personalizada) atualiza o site quando as funções mudam.
- Painel Site → Sobre nós: com a pessoa do sistema escolhida, a opção "Cargo = as funções da pessoa no sistema".
  Desligada, vale o cargo digitado (os cargos já digitados — Estrategista, Gestor de Marketing, CEO — foram mantidos).
- Site: cada função aparece como uma etiqueta separada; no /en as funções conhecidas são traduzidas.
