# 4.67.1 — Baixar áudios (e outras mídias) na Central de Conversas

O Kevin pediu para poder baixar os áudios.

## O que mudou
- Todo áudio tem um botão ⬇ ao lado da duração.
- O menu da mensagem (o que aparece ao passar o mouse ou tocar) ganhou "Baixar" para áudio, foto, vídeo, documento e figurinha.
- O arquivo é salvo direto, sem abrir aba nova.
  - O B7 pega o arquivo pelo mesmo link que usa para tocar ou mostrar e salva com um nome legível, por exemplo `Áudio Luana 2026-11-17 08h23.ogg`.
  - Documento mantém o nome original.
- A extensão vem do tipo do arquivo: ogg, mp3, m4a, jpg, png, webp, mp4, pdf…
- Enquanto baixa, o botão pisca. Se falhar, aparece um aviso.
