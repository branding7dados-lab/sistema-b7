# 4.78.2 — Login com verificação em 2 etapas travava no navegador (achado pelo QA)

O robô de QA entrou como `qa.admin` (admin com app autenticador) e o site mostrou "Sua conta usa verificação em 2 etapas. Atualize o app (ou abra o B7 pelo navegador) para digitar o código." — em vez do campo do código.

Causa: a resposta do segundo passo (`precisa_2fa: true`) leva também um campo `erro`, de propósito, para o app antigo de Android. `B7.DB.chamarAuth` (js/database.js) lança erro sempre que a resposta tem `erro` — então o navegador nunca chegava ao `passoLogin`.

Impacto: qualquer conta que ligasse as 2 etapas (o sistema pede isso aos admins) ficaria trancada fora no navegador; só o "aparelho de confiança" passava. Hoje só as contas de teste têm 2 etapas ligada.

Correção: `chamarAuth` não trata como erro uma resposta com `precisa_2fa`.
