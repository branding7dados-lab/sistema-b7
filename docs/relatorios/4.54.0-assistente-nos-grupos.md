# 4.54.0 — Assistente B7 nos grupos do WhatsApp (o "Gabriel" do B7) (17/11/2026)

Kevin: "vamos fazer um gabriel pra b7 — pode fazer da forma que você faria".
Base: o agente-grupo do Núcleo7 (lido no repositório branding7agencia/nucleo7), refeito para o B7.

## Como funciona
- Nos **grupos ligados a cliente**, quando alguém marca o número conectado (@, inclusive pelo
  código @lid) ou escreve "@<nome do assistente>", ele responde ali, citando a mensagem.
- Contexto: as últimas 25 mensagens do grupo + **o que está em produção para o cliente**
  (vídeos, artes, próximas gravações — mesma leitura do resumo da IA) + aprendizados.
- Não inventa prazo, preço, valor; financeiro nunca. O que não sabe: responde "vou confirmar
  com o time" e manda a dúvida no privado de quem está marcado para receber dúvidas. Quem
  responde **citando o aviso** (ou pela Central → ⋮ → Assistente → Dúvidas) faz a IA reescrever
  a resposta para o cliente e mandar no grupo; a resposta vira **aprendizado**.
- Pode marcar a pessoa da equipe que cuida do assunto ({{marcar:Nome}} → @número).
- "Digitando…" por 4–9 s (configurável) antes de responder.
- Sem marcação fica calado; opção "responder pedidos de ajuda sem ser marcado" (fica calado
  se a equipe falou no grupo nos últimos N min). A equipe escrevendo no grupo não aciona.
- Cada mensagem é avaliada uma vez (wa_assistente_vistos).
